# 信息技术 · 账号与访问安全

**文档编号**：IT-SEC-ACC-2024  

## VPN 与公司网络

- 外网访问内网系统须使用公司发放的 **VPN 客户端**，禁止共享账号。
- VPN 证书或令牌遗失须 **立即** 在 IT 服务台报失并重置。

## 密码策略

- 密码长度不少于 **12 位**，须包含大小写字母、数字及特殊字符中的至少三类。
- **不得**在即时通讯、邮件正文中明文发送密码；应使用公司批准的密码管理或一次性链接方式。

## 权限申请

- 访问生产环境、数据库、代码仓库等敏感资源，须在 **权限工单系统** 中申请，并注明业务理由与期限。
- 权限默认 **最小化**；到期自动回收，延期须重新审批。
